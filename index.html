01 · Ableitungsregeln

Ableitungs-
regeln

Produktregel, Quotientenregel und Kettenregel — immer mit sichtbaren Schritten!

⚠ Ohne GeoGebra — alle Schritte müssen nachvollziehbar sein!
Produktregel
f(x) = u(x) · v(x)
f'(x) = u'(x) · v(x) + u(x) · v'(x)
Merkhilfe: „Strich-normal + normal-Strich"

Beispiel: f(x) = x² · eˣ
u = x²  →  u' = 2x
v = eˣ  →  v' = eˣ
f'(x) = 2x · eˣ + x² · eˣ = eˣ(2x + x²)
Quotientenregel
f(x) = u(x) / v(x)
f'(x) = [u'(x) · v(x) − u(x) · v'(x)] / [v(x)]²
Merkhilfe: Zähler: „Strich-normal minus normal-Strich", Nenner: quadriert

Beispiel: f(x) = x² / (x + 1)
u = x² → u' = 2x  |  v = x+1 → v' = 1
f'(x) = [2x·(x+1) − x²·1] / (x+1)² = (2x² + 2x − x²) / (x+1)² = (x² + 2x) / (x+1)²
Kettenregel
f(x) = g(h(x)) — äußere Funktion von innerer
f'(x) = g'(h(x)) · h'(x) = [äußere Ableitung] · [innere Ableitung]
Vorgehen: 1. Äußere Funktion ableiten (inneres unverändert) · 2. Mit innerer Ableitung multiplizieren

Beispiel: f(x) = (3x² + 1)⁴
Äußere: (...)⁴ → 4(...)³  |  Innere: 3x²+1 → 6x
f'(x) = 4·(3x²+1)³ · 6x = 24x·(3x²+1)³
Weiteres Beispiel: f(x) = sin(x³ − 2)
Äußere: sin(...) → cos(...)  |  Innere: x³−2 → 3x²
f'(x) = cos(x³−2) · 3x²
Kombination
Ketten- + Produktregel kombiniert
Beispiel: f(x) = x² · (2x+1)³
→ Produktregel anwenden: u = x², v = (2x+1)³
→ v' per Kettenregel: 3(2x+1)² · 2 = 6(2x+1)²
f'(x) = 2x·(2x+1)³ + x²·6(2x+1)² = (2x+1)²·[2x(2x+1) + 6x²] = (2x+1)²·(10x² + 2x)
02 · Funktionsanalyse

Funktionen
analysieren

Steigend/fallend, Extrema, Wendestellen, Krümmung und Funktion aus Text aufstellen.

Steigend / fallend
Monotonieverhalten bestimmen
BedingungBedeutung
f'(x) > 0Funktion ist streng steigend
f'(x) < 0Funktion ist streng fallend
f'(x) = 0möglicher Extrempunkt (prüfen!)
Extrempunkte
Hochpunkt / Tiefpunkt berechnen
  1. f'(x) = 0 lösen → x-Kandidaten
  2. f''(x) berechnen und x einsetzen
  3. y-Koordinate: x in f(x) einsetzen
f''(x₀) < 0 → Hochpunkt HP(x₀ | f(x₀)) f''(x₀) > 0 → Tiefpunkt TP(x₀ | f(x₀)) f''(x₀) = 0 → Vorzeichen von f' prüfen!
VZW-Test: Wähle x-Werte links und rechts von x₀. Ändert f'(x) das Vorzeichen (+ → −) = Max, (− → +) = Min, kein Wechsel = Sattelpunkt.
Wendestellen & Krümmung
Wendepunkte berechnen
  1. f''(x) = 0 lösen → Kandidaten
  2. f'''(x) ≠ 0 prüfen oder VZW von f'' prüfen
  3. Wendepunkt: W(x_W | f(x_W))
f''(x) > 0 → Linkskrümmung (konvex, ∪-Form) f''(x) < 0 → Rechtskrümmung (konkav, ∩-Form) f''(x) = 0 → Wendestelle (Krümmungswechsel)
Funktion aufstellen
Aus Text oder Skizze → Gleichungssystem
⚠ Anzahl Variablen = Anzahl Gleichungen!
Vorgehen:
  1. Grad der Funktion bestimmen (z.B. 3 unbekannte → Grad 2 oder 3)
  2. Allgemeinen Ansatz aufschreiben: f(x) = ax³ + bx² + cx + d
  3. Bedingungen einsetzen (Punkte, Extrema, Tangenten, Symmetrie)
  4. GLS mit GeoGebra lösen
GeoGebra: Löse[{Gl1, Gl2, Gl3, Gl4}, {a, b, c, d}]
Typische Bedingungen:
Punkt P(2|5): f(2) = 5
Extremstelle bei x=1: f'(1) = 0
Wendestelle bei x=3: f''(3) = 0
Tangente mit Steigung m: f'(x₀) = m
03 · Kostentheorie

Kosten &
Preistheorie

Kostenfunktionen, Grenzkosten, Betriebsoptimum und Preisuntergrenzen.

Kostenarten
K(x) aufteilen
Kf = K(0) (Fixkosten) Kv(x) = K(x) − Kf (variable Kosten) K(x) = Kv(x) + Kf
Grenzfunktionen
1. Ableitungen
K'(x) = Grenzkostenfunktion E'(x) = Grenzerlösfunktion G'(x) = Grenzgewinnfunktion
Ertragsgesetzliche Kostenfunktion
Eigenschaften & Kostenkehre
Typische Form: K(x) = ax³ − bx² + cx + d  (a > 0)

Verlauf: erst degressiv (Kosten steigen langsamer) → dann progressiv (steigen schneller)
Kostenkehre = Wendepunkt der Kostenfunktion: K''(x) = 0 → Minimum der Grenzkostenfunktion K'(x)
Progressiver Kostenverlauf: K'' > 0 (konvex, Kosten steigen immer schneller)
Degressiver Kostenverlauf: K'' < 0 (konkav, Kosten steigen langsamer)
Durchschnittskosten
k(x) = K(x) / x und kv(x) = Kv(x) / x
FunktionMinimumBedeutung
k(x) = K(x)/xBetriebsoptimum
k'(x) = 0		Langfristige Preisuntergrenze
Unter diesem Preis → dauerhafter Verlust
kv(x) = Kv(x)/xBetriebsminimum
kv'(x) = 0		Kurzfristige Preisuntergrenze
Unter diesem Preis → Produktion sofort einstellen
GeoGebra: Löse[k'(x) = 0, x] Einheit: €/ME
Graphen zuordnen
Reihenfolge der Kurven erkennen
  • K(x) schneidet die y-Achse bei Kf > 0 (nicht im Ursprung!)
  • k(x) hat ein Minimum = Betriebsoptimum
  • K'(x) schneidet k(x) im Minimum von k(x) → wichtig!
  • kv(x) liegt immer unterhalb von k(x) (kein Fixkostenanteil)
  • K'(x) schneidet kv(x) im Minimum von kv(x)

Angebot,
Nachfrage & Erlös

Preisfunktionen, Marktgleichgewicht und Erlösfunktion.

Nachfrage & Angebot
Preisfunktionen
BegriffFormel / Eigenschaft
Nachfrage p_N(x)Fallend: je mehr angeboten, desto günstiger
Höchstpreisp_N(0) — Preis wenn x = 0
Sättigungsmengep_N(x) = 0 → Nullstelle der Nachfragefunktion

Erlösfunktion
E(x) = p(x) · x
Erlösfunktion aus der Nachfragepreisfunktion ableiten:
E(x) = p_N(x) · x
AufgabeVorgehen
ErlösgrenzenE(x) = 0 → Nullstellen: x = 0 und Sättigungsmenge
Maximaler ErlösE'(x) = 0 → x_max, dann E(x_max)

Beispiel komplett
Nachfrage → Erlös → Maximum
Gegeben: p(x) = −2x + 20
E(x) = p(x)·x = (−2x+20)·x = −2x² + 20x E'(x) = −4x + 20 = 0 → x = 5 E(5) = −2·25 + 20·5 = −50 + 100 = 50 € Erlösgrenzen: E(x) = 0 → x = 0 und x = 10 Erlöszone: 0 < x < 10 (auf der x-Achse!)
05 · Gewinnfunktion

Gewinn-
funktion

G(x), Gewinngrenzen, Gewinnmaximum und Graphen zuordnen.

⚠ Gewinnzone immer auf der x-Achse angeben! Einheiten nicht vergessen (ME, €).
Gewinnfunktion
G(x) = E(x) − K(x)
G(x) = E(x) − K(x) G(x) = p(x)·x − K(x)
G > 0: Gewinn (Profit)  |  G < 0: Verlust  |  G = 0: Gewinnschwelle (BEP)
Gewinngrenzen (BEP)
Break-Even-Points berechnen
G(x) = 0 → Löse[G(x) = 0, x] → x₁ = untere Gewinngrenze (BEP 1) → x₂ = obere Gewinngrenze (BEP 2) Gewinnzone: x₁ < x < x₂ (auf x-Achse!)
ACHTUNG: Schnittpunkte von E(x) und K(x) ergeben dieselben BEPs → G = E − K = 0 dort wo E = K
Gewinnmaximum
Gewinnmaximierende Menge berechnen
G'(x) = 0 → x_max bestimmen G''(x_max) < 0 → bestätigt Maximum Gleichbedeutend: E'(x) = K'(x) (Grenzerlös = Grenzkosten)
Gewinnmaximum: x_max in G(x) einsetzen → G(x_max) in €
Gewinnmaximierende Menge: x_max in ME
Graphen K(x), E(x), G(x) zuordnen
Merkmale der drei Kurven
KurveErkennungsmerkmal
K(x)Schneidet y-Achse bei Kf > 0 (nicht im Ursprung)
E(x)Geht durch Ursprung (0|0), bei linearer p(x): Parabel
G(x)= E − K, liegt unter x-Achse wenn Verlust
Schnittpunkte von K und E = Nullstellen von G = BEPs
Maximaler Abstand E über K = Gewinnmaximum
Übungsaufgaben

Mathe
üben

Beispiele im Maturaformat — erst selbst lösen, dann Lösung aufklappen!

01
Produktregel
Leite ab: f(x) = (2x³ − 1) · (x² + 3x)
u = 2x³ − 1 → u' = 6x²
v = x² + 3x → v' = 2x + 3
f'(x) = 6x² · (x²+3x) + (2x³−1) · (2x+3)
= 6x⁴ + 18x³ + 4x⁴ + 6x³ − 2x − 3
f'(x) = 10x⁴ + 24x³ − 2x − 3
02
Kettenregel
Leite ab: f(x) = (x³ − 2x)⁵
Äußere Funktion: (...)⁵ → 5(...)⁴
Innere Funktion: x³ − 2x → 3x² − 2
f'(x) = 5·(x³−2x)⁴ · (3x²−2)
03
Extrema & Wendestelle
f(x) = x³ − 6x² + 9x + 1  — Bestimme Extrema und Wendestelle.
f'(x) = 3x² − 12x + 9 = 0 → x² − 4x + 3 = 0
→ (x−1)(x−3) = 0 → x₁ = 1, x₂ = 3
f''(x) = 6x − 12
f''(1) = −6 < 0 → Hochpunkt HP(1 | 5)
f''(3) = +6 > 0 → Tiefpunkt TP(3 | 1)
Wendestelle: f''(x) = 0 → 6x−12 = 0 → x = 2
Wendepunkt W(2 | f(2)) = W(2 | 3)
04
Betriebsoptimum
K(x) = 0,1x³ − 1,5x² + 8x + 20  — Bestimme Betriebsoptimum (langfristige Preisuntergrenze).
k(x) = K(x)/x = 0,1x² − 1,5x + 8 + 20/x
k'(x) = 0,2x − 1,5 − 20/x² = 0
GeoGebra: Löse[k'(x) = 0, x] → x ≈ 5,2
k(5,2) einsetzen → langfristige Preisuntergrenze in €/ME
Betriebsoptimum bei x ≈ 5,2 ME
05
Gewinnmaximum (Maturaformat)
K(x) = x³ − 6x² + 20x + 10,  p(x) = −0,5x + 18  — Gewinnmaximierende Menge & Gewinnmaximum.
E(x) = p(x)·x = (−0,5x + 18)·x = −0,5x² + 18x
G(x) = E(x) − K(x) = −0,5x²+18x − (x³−6x²+20x+10)
G(x) = −x³ + 5,5x² − 2x − 10
G'(x) = −3x² + 11x − 2 = 0
GeoGebra: Löse[G'(x)=0, x] → x₁ ≈ 0,19, x₂ ≈ 3,47
G''(x) = −6x + 11; G''(3,47) = −9,82 < 0 → Maximum
Gewinnmaximum bei x ≈ 3,47 ME, G(3,47) ≈ max. Gewinn in €
06
Marktgleichgewicht
p_N(x) = −x + 12,  p_A(x) = 0,5x + 3  — Gleichgewichtsmenge und Marktpreis.
Gleichgewicht: p_N(x) = p_A(x)
−x + 12 = 0,5x + 3
9 = 1,5x → x* = 6
p* = p_N(6) = −6 + 12 = 6 (Probe: p_A(6) = 3+3 = 6 ✓)
Gleichgewichtsmenge: x* = 6 ME, Marktpreis: p* = 6 €/ME
07
Funktion aus Text aufstellen
Eine Funktion 3. Grades hat einen Hochpunkt bei HP(1|4) und einen Tiefpunkt bei TP(3|0). Stelle f(x) auf.
Ansatz: f(x) = ax³ + bx² + cx + d (4 Unbekannte → 4 Gleichungen)
f(1) = 4: a + b + c + d = 4
f(3) = 0: 27a + 9b + 3c + d = 0
f'(1) = 0: 3a + 2b + c = 0 (Extremstelle)
f'(3) = 0: 27a + 6b + c = 0 (Extremstelle)
GeoGebra: Löse[{a+b+c+d=4, 27a+9b+3c+d=0, 3a+2b+c=0, 27a+6b+c=0}, {a,b,c,d}]
→ a = 1, b = −6, c = 9, d = 0 → f(x) = x³ − 6x² + 9x
